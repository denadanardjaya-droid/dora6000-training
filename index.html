Cara Membagikan Portal Ini ke Tim

Tanpa server, tanpa biaya, tanpa konfigurasi rumit — cukup GitHub gratis. Selesai dalam 10 menit.

LANGKAH 01

Buat akun & repo GitHub

Daftar di github.com (gratis). Klik tombol + → New repository. Beri nama misalnya training-dora6000. Pilih Public. Klik Create.

LANGKAH 02

Upload semua file HTML

Di halaman repo, klik Add file → Upload files. Drag & drop semua file: index.html, Modul1_..., Modul2_..., dst. Klik Commit changes.

LANGKAH 03

Aktifkan GitHub Pages

Klik tab Settings di repo. Scroll ke bagian Pages (menu kiri). Di "Branch", pilih main dan folder / (root). Klik Save.

LANGKAH 04

Bagikan link ke tim

Tunggu 1–2 menit. GitHub akan menampilkan link berwarna hijau di halaman Pages. Copy link tersebut dan bagikan via WhatsApp/email ke seluruh tim sales & teknisi.

Format URL Anda: https://username.github.io/training-dora6000/
Contoh nyata: https://vitalhealthcare.github.io/training-dora6000/
Update materi Cukup upload ulang file HTML yang diubah ke repo. GitHub Pages otomatis memperbarui dalam 1–2 menit. Tidak perlu restart server apapun.
Akses dari HP Link GitHub Pages bisa dibuka di browser HP (Chrome/Safari) tanpa install aplikasi. Semua materi responsive untuk layar kecil.
Privasi Repo Public = siapa saja bisa akses jika tahu link. Jika perlu privat, upgrade ke GitHub Pro (~$4/bulan) untuk Pages dari repo Private.
